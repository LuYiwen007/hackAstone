# Cognitive Arena（认知竞技场）

> 与古今哲学家辩论，审视你的思维盲区

**Cognitive Arena** 是一款基于 HarmonyOS NEXT 的 AI 哲学思辨教育应用。用户可以与历史哲学家进行实时对话辩论，通过"对抗式思考"激发批判性思维，揭示认知偏差。

## ✨ 核心功能

### 🗺️ 哲学地图 & 时间轴
- 交互式世界地图，按区域和时代浏览哲学家
- 时间轴横跨古代 → 中世纪 → 近代 → 现代
- 查看哲学家学派、核心思想、代表著作

### ⚔️ 哲学辩论（1v1）
- 选择一位哲学家，AI 自动生成辩题
- 选择立场（赞同 / 反对 / 不确定）
- 三方对话：用户 ↔ 哲学家 AI ↔ 裁判 AI
- 裁判可介入追问、引导，甚至让哲学家反问用户
- 辩论结束后生成全面视角总结

### 🔬 学科辩论（Builder vs Breaker）
- 一方建设观点（Builder），一方解构观点（Breaker）
- 用户可选边站或保持"不确定"（双方同时辩论）
- 涵盖科学、伦理、政治等多学科议题

### ⚠️ 道德困境
- 经典思想实验：电车难题、缸中之脑等
- 选择立场 + 选择哲学家进行深度对话
- 裁判 AI 主持讨论，可让哲学家互相质询
- 最终生成深度分析报告

### 👥 圆桌会议
- 自选 2~4 位哲学家 + 自定义辩题
- 哲学家依次开场发言，用户可随时插入提问
- 模拟"跨时空哲学沙龙"

### 🧠 思维档案（Mind Profile）
- 认知偏差地图：确认偏差、幸存者偏差等量化分析
- 统计数据：对局数、改变立场次数、思维盲区、判断准确率
- 近期对局记录 & 关键洞察

### 👤 用户体系
- 注册 / 登录（邮箱 + 密码）
- 头像上传 & 个人设置
- 辩论记录自动保存至服务端

## 🛠️ 技术栈

| 层级 | 技术选型 |
|------|---------|
| 前端框架 | ArkTS / ArkUI（HarmonyOS NEXT） |
| 开发工具 | DevEco Studio |
| 网络通信 | `@kit.NetworkKit`（HTTP + SSE 流式） |
| 状态管理 | `@StorageLink` + 全局 Store 单例 |
| 路由导航 | 自定义 NavPathStack 路由 |
| 国际化 | 中英双语（运行时切换） |
| 后端 | RESTful API + SSE 流式 Agent |
